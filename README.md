# SkillScribe

Cost per skill point for every recipe, plus a Plan window: what to learn next (trainer, AH, vendor, drops) and the cheapest route to your skill cap. Uses MarketScribe prices and Wowhead Forever recipe data.

An addon for **World of Warcraft: Forever** (interface 16001), made for personal use and shared as-is.

## Install

**Requires MarketScribe** — install it first.

- **WowUp:** Add Addon → Install from URL → paste this repository's URL. Updates come with each new release.
- **Manual:** download `SkillScribe-<version>.zip` from the Releases page and unzip it so the `SkillScribe` folder sits in `_forever_\Interface\AddOns\`.

Type `/reload` in game after updating.

## Data

Recipe data in `Recipes.lua` comes from Wowhead's WoW: Forever database.
